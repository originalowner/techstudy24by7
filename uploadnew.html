AI Blog Generator

Instructions

Paste a valid JSON object in the editor below. The JSON will be sent to AWS API Gateway, where your backend (Lambda + Gemini) can generate a complete HTML blog article.

Required Fields

  • title – Blog title
  • slug – URL-friendly blog identifier
  • category – Blog category (AWS, Linux, DevOps, etc.)
  • author – Author name
  • publishedDate – Date in YYYY-MM-DD format
  • topicDetails – Detailed instructions for Gemini to generate the article

Example Input

{
  "title": "This Is A Blog",
  "slug": "this-is-a-blog",
  "category": "Linux",
  "author": "John Doe",
  "publishedDate": "2026-05-31",
  "topicDetails": "Explain AWS RDS features that improve database reliability and robustness, including Multi-AZ, backups, monitoring, failover, scaling, and real-world examples."
}
