Installation of Elasticsearch, Kibana and Logstash (ELK) on Ubuntu 24 Server

The ELK Stack—Elasticsearch, Kibana, and Logstash—is a popular open-source platform used for centralized logging, search, and data visualization. This guide explains how to install and configure the ELK Stack on an Ubuntu 24 Server.

Prerequisites

  • Ubuntu 24 Server
  • User with sudo privileges
  • At least 4 GB RAM
  • Active internet connection

Step 1: Update the System

Start by updating your system packages:

sudo apt update && sudo apt upgrade -y

Step 2: Install Java

Elasticsearch requires Java. Install OpenJDK 17:

sudo apt install openjdk-17-jdk -y

Verify the installation:

java -version

Step 3: Add Elastic Repository

Import the Elastic GPG key:

curl -fsSL https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elastic-keyring.gpg

Add the Elastic APT repository:


echo "deb [signed-by=/usr/share/keyrings/elastic-keyring.gpg] https://artifacts.elastic.co/packages/8.x/apt stable main" |
sudo tee /etc/apt/sources.list.d/elastic-8.x.list

Update package list:

sudo apt update

Step 4: Install Elasticsearch

Install Elasticsearch:

sudo apt install elasticsearch -y

Edit the Elasticsearch configuration file:

sudo nano /etc/elasticsearch/elasticsearch.yml

Update or verify the following settings:


network.host: localhost
http.port: 9200

Start and enable Elasticsearch:


sudo systemctl start elasticsearch
sudo systemctl enable elasticsearch

Verify Elasticsearch is running:

curl http://localhost:9200

Step 5: Install Kibana

Install Kibana:

sudo apt install kibana -y

Edit Kibana configuration:

sudo nano /etc/kibana/kibana.yml

Configure Kibana settings:


server.port: 5601
server.host: "0.0.0.0"
elasticsearch.hosts: ["http://localhost:9200"]

Start and enable Kibana:


sudo systemctl start kibana
sudo systemctl enable kibana

Access Kibana using:

http://<server-ip>:5601

Step 6: Install Logstash

Install Logstash:

sudo apt install logstash -y

Create a basic Logstash pipeline configuration:

sudo nano /etc/logstash/conf.d/logstash.conf

Add the following content:


input {
  beats {
    port => 5044
  }
}

output {
  elasticsearch {
    hosts => ["localhost:9200"]
  }
}

Start and enable Logstash:


sudo systemctl start logstash
sudo systemctl enable logstash

Step 7: Verify ELK Stack Services

Check the status of the ELK services:


sudo systemctl status elasticsearch
sudo systemctl status kibana
sudo systemctl status logstash

Conclusion

You have successfully installed the ELK Stack on Ubuntu 24 Server. This setup enables centralized log collection, search, and visualization. You can now integrate Beats, create dashboards in Kibana, and customize Logstash pipelines based on your logging requirements.
